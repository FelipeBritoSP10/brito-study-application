## 🎓 Sobre o Projeto

O **Brito Study** é uma aplicação web desenvolvida como **projeto acadêmico da Universidade Estácio de Sá**, na disciplina de **Desenvolvimento Web**.

O sistema foi criado com o objetivo de auxiliar estudantes no registro e organização de conteúdos estudados, permitindo armazenar anotações de forma simples, rápida e eficiente diretamente no navegador.

Além da funcionalidade prática, o projeto tem como foco a aplicação dos conceitos estudados em sala de aula, incluindo manipulação do DOM, modularização de código, persistência de dados e boas práticas de desenvolvimento Front-End.

## 🏗️ Arquitetura do Projeto

O sistema foi organizado utilizando uma arquitetura modular para facilitar a manutenção e escalabilidade.

### 📂 App

Responsável pela lógica principal da aplicação:

* Cadastro de anotações
* Exclusão de registros
* Controle dos dados
* Atualização da interface

### 📂 DOM

Responsável pela interação com os elementos da página:

* Busca de elementos
* Atualização de conteúdo
* Limpeza de campos
* Renderização dos componentes

### 📂 StorageManager

Responsável pelo gerenciamento dos dados:

* Salvar informações
* Recuperar registros
* Comunicação com o Local Storage

## 🚀 Como Executar

```bash
git clone https://github.com/FelipeBritoSP10/brito-study-application
```

### 2️⃣ Entrar na Pasta

## 📖 Como Utilizar

1. Informe a matéria estudada.
2. Digite o conteúdo da anotação.
3. Clique em **Salvar**.
4. Visualize suas anotações cadastradas.
5. Utilize **Remover** para excluir registros quando necessário.
